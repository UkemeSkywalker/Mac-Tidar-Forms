# Google Stitch prompts: Mac Tidar Forms

Start each Stitch session with the shared style, then paste one screen prompt. Export results to `designs/<screen>/`.

## Shared style

Mac Tidar Forms is a form builder from Mac Tidar, used by small African businesses and teams. Style: calm, editorial, modern. Colours: deep forest green #16382C for primary actions, mint #BFE8D2 and #E6F5EC for accents, warm linen #F7F4EC background, paper #FFFDF8 cards, hairline #E2DCCD borders, charcoal #1D2320 text, muted #66706A secondary text, brick #A8322A for errors. Font: Inter. Rounded 8 to 14px corners, thin borders, no heavy shadows, no gradients. Responsive web app, usable at 375px wide.

## 1. Marketing homepage

Design the homepage. Headline: "Build a form. Share a link. Watch the answers add up." Include a top bar with logo and Sign in, a hero with a Create your first form button and a product visual of a form beside a live spreadsheet, three sections (build, share, understand), a pricing teaser and a footer.

## 2. Sign in and sign up

Design centred auth cards on linen. Sign in: email, password, primary button, link to create an account. Sign up: name, email, password with an 8-character hint. Show an inline error state.

## 3. Forms list

Design the signed-in home. Header with logo, user name, Sign out. Title "Your forms" with a New form button. A responsive card grid; each card has form title, Live or Draft pill, response count and last-updated date. Include the empty state.

## 4. Form builder

Design the question editor. Tabs: Questions, Spreadsheet, Dashboard. A sticky toolbar with Save, Publish or Unpublish, Copy link, Preview and a quiet Delete form. A centred column with a title and description card, then one card per question: question text, type selector (short answer, paragraph, email, number, date, multiple choice, checkboxes, dropdown, rating 1 to 5), help text, editable options with remove buttons, a Required toggle, move up and down, remove. Finish with Add question.

## 5. Public form

Design the page a respondent sees, with no app navigation. A narrow column with a title card and one card per question, showing every question type. Rating is a row of five square buttons. Required questions have a red asterisk. Include a validation error state, the Submit button, a thank-you state and a small "Powered by Mac Tidar Forms" footer. Must feel excellent on a phone.

## 6. Responses spreadsheet

Design a spreadsheet view on the Spreadsheet tab: search box, "4 of 4" count, Download Excel and Download CSV buttons. A dense grid with a sticky mint header, row numbers, thin cell borders, horizontal scroll and a quiet Delete on each row. Include the empty state.

## 7. Dashboard

Design the Dashboard tab: three stat tiles (Total responses, Last 7 days, Latest response), a thin-column chart of responses per day for 30 days in one forest green, then a two-column grid of question cards. Choice questions use horizontal bars with count and percentage, rating adds an average, number shows average, min and max, and text shows the latest five answers. Include hover tooltips and an empty state.
